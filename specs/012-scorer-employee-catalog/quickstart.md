# Quickstart

## 本地更新

本地源码已修改，不需 git pull。在项目根目录执行 `docker compose up -d --build`，沿用既有地址和管理员，不改 .env 或数据库。

## 页面验证

1. 进入评分职责，刷新后新增职责，打开评分人下拉。
2. 确认可见 CTO 朱亮、子部门负责人毛一凡/王成斌、普通员工王绍品；逐个选择后取消即可，不需保存真实职责。
3. 切换职责类型 CTO，名单不受系统角色过滤。
4. 编辑已有职责，当前评分人正确显示；取消，配置和旧考核不变。
5. 停用或范围外员工不应出现，不绕过员工查看授权。
6. 接口断开或任意分页失败时显示失败和刷新入口，不能新增、编辑、保存；恢复后刷新可重试。
