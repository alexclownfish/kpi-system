# Quickstart: 绩效结果打印签字与归档

## 自动验证

```bash
cd server && go test ./...
npx tsc --noEmit
npm run build
docker compose config
```

## 手工场景 A：纸质签字

1. 使用 HR 账号打开一条 `待确认` 考核。
2. 点击“导出最终评分表”，检查文件名、结果版本、校验码、最终分和签字栏。
3. 打印或模拟签字后，打开“登记纸质签字”。
4. 填写签字日期，上传不超过 10 MB 的 PDF/JPG/PNG。
5. 确认成功后检查状态为“已完成”，详情显示纸质确认信息并能下载附件。
6. 尝试编辑评分或重复确认，应得到明确拒绝提示。

## 手工场景 B：在线确认

1. 使用被考核员工账号打开本人 `待确认` 考核。
2. 点击“确认最终得分”。
3. 检查状态为“已完成”，详情显示在线确认、确认时间和结果版本。

## 权限验证

1. 使用无权访问该考核的员工，直接请求导出和附件下载 URL。
2. 预期返回 403 或 404，响应不得包含员工、评分或附件内容。

## 过期版本验证

1. HR 导出一条待确认考核。
2. 在允许的异议处理流程中调整最终结果。
3. 尝试登记旧纸质签字，应提示结果已变化并要求重新导出。
