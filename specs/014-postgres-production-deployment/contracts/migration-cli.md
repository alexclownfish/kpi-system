# 一次性迁移 CLI 契约

输入：只读的 SQLite 一致性副本路径及 SHA-256、显式目标库名和空库确认；PostgreSQL 连接参数沿用 PGHOST、PGPORT、PGUSER、PGDATABASE、PGPASSWORD_FILE。目标 schema 已由受限应用角色初始化且业务表为空；一次性迁移容器独立挂载管理员口令并使用管理员角色，常规后端绝不持有该口令。

输出：每张源业务表的行数、迁移行数与验证结果；目标关键关联/序列检查；整体成功或非零退出码。输出不得包含明文凭据和密码哈希。

拒绝条件：源库不可读、目标库已有业务行、源表或源列无法映射、任一数据值/约束不能迁移、行数不一致、关联/序列检查失败。失败后不启动应用；不得自动删除旧库或覆盖目标中已有数据。

备份 API：PostgreSQL 模式的旧页面创建备份及恢复操作返回明确错误；全量备份/恢复改由维护窗口执行命令，而非把旧 SQLite SQL 文件当作 PG 备份。
