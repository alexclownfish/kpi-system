# Quickstart: 绩效计算引擎与模板维护

## 1. 模板发布

1. 以具备 KPI 编辑权限的账号进入绩效模板页面。
2. 创建一个工程师模板，添加维度：20、40、15、5、20。
3. 在“交付质量”中添加多个指标，并配置维度内权重，使该维度内权重合计为 100。
4. 验证综合权重合计为 100 后发布模板。
5. 将其中一个权重改为导致总和不为 100，确认发布被拒绝且没有半成品版本。

## 2. 岗位自动匹配

1. 为两个岗位配置不同模板。
2. 分别创建考核。
3. 验证考核实例使用正确的模板版本、指标和评分人类型。
4. 修改模板后再次查看旧考核，确认其快照不变。

## 3. 评分和确认前置条件

1. 为每个必填指标生成评分任务。
2. 只完成部分指标，尝试进入员工确认，必须返回未完成指标清单。
3. 完成全部必填指标，验证多人评分取平均。
4. 验证总分等于每项指标加权分之和，等级按 S/A/B/C/D 阈值计算。
5. 验证空白评分不会被当成 0 分或 D 等级。

## 4. HR 汇总

1. 创建两个项目投入记录：一个投入占比 10%，一个投入占比 50%。
2. 验证 10% 项目加权贡献为 0，50% 项目按总分乘 50% 计算。
3. 验证月度、季度和年度同时返回分数与等级。
