# 导出职责与加权字段验收记录

日期：2026-10-12。范围：T104/T105。该增量只覆盖新流程 weighted-v2 的签字栏默认值和结果明细导出字段，不执行 Compose 重建，也不修改已有数据库数据。

## 已实现行为

- 新考核创建时，从模板逐指标解析出的评分职责生成默认签字栏：员工签字、项目经理/部门负责人/产品经理/CTO 等实际职责签字。职责顺序按模板评分任务首次出现顺序保留。
- 模板明确配置的自定义签字栏优先；已创建考核只使用其 `TemplateSnapshotJSON` 内的签字布局，后续模板修改不会改变历史导出。
- weighted-v2 导出支持维度、维度权重、指标、指标权重、综合权重、评分职责、实际评分人、加权贡献、最终得分、评分等级等字段。评分等级同时显示在 PDF/Excel 结果摘要，并可作为明细列选择；旧版自评、主管、HR 和最终评价字段继续可用。
- 单份 Excel/PDF 继续通过同一结果快照和版式生成；未选中的新字段不会出现在导出文件中。`actual_scorers` 同时作为 `scorer_name` 的兼容字段接受。

## 页面验收

1. 用 HR/管理员登录模板管理，打开一个草稿或复制一个新版本；在“结果导出设置”切换“评分过程完整版”。
2. 确认字段列表能选择维度、维度权重、指标权重、综合权重、评分职责、实际评分人、加权贡献；保存版式并发布新版本。
3. 创建一条新考核并完成必填评分，进入员工确认阶段。
4. 在考核详情分别导出 Excel 和 PDF，核对两份文件都包含所选字段、同一总分、评分等级和加权贡献；PDF 应为 A4 竖向。旧版快照没有等级字段时按其最终总分派生等级，不能改变快照校验码。
5. 核对签字区显示该考核模板实际评分职责。复制模板修改签字栏后，新考核使用新值；已完成旧考核仍保持原签字栏。
