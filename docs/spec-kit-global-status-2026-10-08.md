## 开发闭环约束

每一个后续增量都按以下顺序执行并留下证据：

`当前状态 → 明确下一任务 → 规格/计划/任务核对 → 先写失败回归 → 实现 → 自动化测试 → 真实页面/API 验收 → 修复 → 回归 → 更新 acceptance/converge`。
